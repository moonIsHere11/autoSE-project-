*Run on 6 Nov 2026 (scope: Java only), `python -m tools.selftest --lang java --mutants 3 --mode full`,

## How to read it

* **False positives: 0.** On all 14 correct Java translations no tier reported FAIL. Every program
  passes T0 and T1 (265–408 generated inputs each, byte-identical to GnuCOBOL 3.2).
* **Levels reached by correct paragraphs:** 101 units. All reach level ≥ 1 (T1). 18 reach level 2 or 3 (5 of them level 3):
  * whole-program exhaustive proofs (T2a) on DIVREM, TAXCALC, TEMPCONV;
  * complete JBMC proofs (T2b) on DIVREM/INVENTORY `SET-RETURN` and PAYROLL `SPLIT-HOURS`;
  * T3 contract proofs on 7 programs.
* **Not accepted although correct (8 units), never because of a FAIL:**
  * MERGE2: 4 empty `*-EXIT` paragraphs; the T2b vacuity run was killed by the 3 GB memory cap.
  * PAYROLL: 3 units with T3 TIMEOUT.
  * INVENTORY: `VALIDATE-RECORD`, T3 ERROR "contradictory preconditions" (see LIMITATIONS.md).
* **Planted bugs: 71% caught (29/41 live mutants), all by T1.** This is below the proposal's 90% target.
  * Branch swaps 100%, comparison flips 86%, loop bounds 50%, `double` arithmetic 11%.
  * 8 of the 12 survivors replace exact integer/BigDecimal arithmetic with `double` inside an
    expression. T0 only flags `double` *fields*, not `double` intermediate arithmetic. For the small
    PIC sizes in the corpus, doubles are exact (< 2^53), so several of these mutants are probably
    behaviourally equivalent and undetectable by any tier. That has **not** been proven
    mutant-by-mutant, so they are counted as survived.
  * The other 4 (two comparison flips, two loop bounds) were not exercised by the generated inputs
    (e.g. in helper code on paths the program never reaches) or are equivalent; not yet reviewed.
* **Why T2b/T3 caught none of the mutants:** mutants are sampled at random over each program (3 per
  program), and only 7/101 units are T2b-eligible and 18/101 T3-eligible. No sampled mutant landed
  in an eligible unit. T2b's ability to catch a bug that T1 misses is shown separately by the e2e
  test `tests/e2e/test_t2b_t3_e2e.py::test_t2b_refutes_a_planted_bug_with_a_concrete_counterexample`.
* **Time:** about 30–240 s per program in full mode (T1 ≈ 31 s, T3 ≈ 37 s mean). The whole self-test
  took 84 min.
